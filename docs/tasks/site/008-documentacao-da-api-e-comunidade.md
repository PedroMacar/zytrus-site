# 008 - Documentação da API e comunidade

## Objectivo
Os programadores encontram a documentação da API a partir do site, e os
utilizadores encontram a comunidade.

Depende de duas decisões do Pedro: se a API fica aberta aos clientes com
credenciais próprias, e qual é o canal da comunidade.

## Passo-a-passo
1. Página "Documentação da API": apresentação, como autenticar e ligação à
   referência. A referência é gerada no build a partir de
   `backend/docs/api/openapi.json`.
2. Se a API ainda não estiver aberta aos clientes, a página diz que está a
   caminho e a referência não é publicada.
3. O exemplo de pedido e resposta é copiado de uma chamada real, nunca
   escrito à mão.
4. Página "Comunidade": explica o canal escolhido e leva até ele. Sem
   canal decidido, a página e as ligações não são publicadas.
