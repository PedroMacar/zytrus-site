# 006 - Integrações

## Objectivo
A página de integrações lista as ligações existentes, com filtro por
categoria e estado (desenho "Integrações").

## Passo-a-passo
1. Ficheiro de dados com cada integração: nome, categoria, descrição,
   estado ("Disponível" ou "Em estudo") e logótipo.
2. Disponíveis hoje: M-Pesa, e-Mola e cartão bancário (pagamento da
   subscrição) e a API do Zytrus.
3. Filtro por categoria no browser, sem recarregar a página.
4. "Em estudo" só com integrações que o Pedro confirmar; sem nenhuma, a
   secção não aparece.
5. Bloco "Falta alguma ligação?" com ligação ao contacto.
6. Logótipos de terceiros só com as regras de uso de cada marca
   respeitadas; sem isso, fica o nome em texto.
